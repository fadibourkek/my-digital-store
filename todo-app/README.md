# TaskMaster - تطبيق قائمة المهام

تطبيق حديث وميزات غنية لإدارة المهام اليومية مع إمكانية التخزين المحلي.

## المميزات

✅ إدارة المهام (إضافة/تعديل/حذف)
✅ تحديد الأولويات (منخفضة/متوسطة/عالية)
✅ تاريخ الاستحقاق
✅ تنظيم في مشاريع ملونة
✅ بحث فوري
✅ تصفية ذكية
✅ ترتيب متعدد
✅ إحصائيات حية
✅ تخزين محلي تلقائي

## الاستخدام

1. افتح `index.html` بالمتصفح
2. أضف مهمتك
3. نظمها في مشاريع
4. تتبع إنجازك

## البيانات

كل البيانات تُحفظ محلياً في متصفحك - آمنة وخاصة 100%
